# Evelin Power

Evelin személyes márkájának és digitális jelenlétének projektalapja.

## Cél

Egy letisztult, mobilon is jól használható oldal, amely világosan bemutatja a márkát, a tartalmakat és az elérhető kapcsolatfelvételi módokat.

## Tervezett oldalszerkezet

1. **Kezdőlap** – rövid bemutatkozás és a márka fő üzenete.
2. **Tartalmak** – cikkek, gondolatok vagy hasznos anyagok.
3. **Projektek** – nyilvánosan vállalható munkák és digitális anyagok.
4. **Kapcsolat** – kizárólag külön erre a célra létrehozott, nyilvános elérhetőség.

## Következő fejlesztési lépések

- [ ] A nyilvános márkanév és a célközönség véglegesítése.
- [ ] A kezdőlap szövegének és vizuális stílusának kiválasztása.
- [ ] Mobilnézet ellenőrzése.
- [ ] Kapcsolati és adatvédelmi információk előkészítése.
- [ ] GitHub Pages vagy más tárhely kiválasztása a publikálás előtt.

## Adatvédelmi alapelvek

- Ne kerüljön az oldalra lakcím, személyes telefonszám, privát e-mail-cím vagy a gyerekekre vonatkozó adat.
- Kapcsolatfelvételhez külön, nyilvános üzleti elérhetőséget használj.
- A publikálás előtt ellenőrizd az összes linket, képet, szöveget és metaadatot.

## Állapot

Ez a repository jelenleg projektterv. A weboldal még nincs publikálva.
